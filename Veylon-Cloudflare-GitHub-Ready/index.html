Technical Details

Frequently asked questions

Do I need to configure any router ports or server IP addresses?
No. Veylon communicates strictly over standard outbound HTTPS/WSS port 443. Launch the app, create your account, and start adding friends immediately across any ISP or mobile hotspot.
Can I use Veylon both on Windows Desktop and in my web browser?
Yes. Your account, friends, spaces, messages, and cosmetics sync in real time between the native Windows x64 app (Veylon-Setup.exe) and the web app (/channels/@me).
What happens if Windows SmartScreen shows a prompt during setup?
Click More info then Run anyway. You can also verify package integrity anytime against the published SHA-512 hash using the Copy SHA-512 button above or /latest.yml.
How do software updates work once Veylon is installed?
Veylon includes a built-in SHA-512 verified desktop updater and keeps your session, settings, and media intact across every release.
